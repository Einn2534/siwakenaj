# Audio Sources

These files are loaded by `SoundManager` through `Resources.Load<AudioClip>("Audio/...")`.

| Local file | Purpose | Source | License |
| --- | --- | --- | --- |
| `Bgm.wav` | Looping gameplay BGM | "Two Simple Game Music Loops" by qubodup, `levelmusicloop-tigrun.wav` https://opengameart.org/content/two-simple-game-music-loops | CC0 |
| `TitleBgm.ogg` | Looping title BGM | "Two Simple Game Music Loops" by qubodup, `menumusicloop-tiggo.ogg` https://opengameart.org/content/two-simple-game-music-loops | CC0 |
| `StageSelectBgm.ogg` | Looping stage select BGM | "8bit Action Stage Select" by MintoDog, `select_plains_bpm100.ogg` https://opengameart.org/content/8bit-action-stage-select | CC0 |
| `Correct.wav` | Correct answer SE | "Point bell" by Brandon75689 / HaelDB, `sd_0.wav` https://opengameart.org/content/point-bell | CC0 |
| `Miss.wav` | Miss SE | "Game Over Trumpet SFX" by 0new4y, `losetrumpet.wav` https://opengameart.org/content/game-over-trumpet-sfx | CC0 |
| `Clear.wav` | Stage clear SE | "Win sound effect" by Listener, `Win sound.wav` https://opengameart.org/content/win-sound-effect | CC0 |
| `GameOver.wav` | Game over SE | "Game Over!" by zuvizu, `GAMEOVER.wav` https://opengameart.org/content/game-over-0 | CC0 |

`GameOver.wav` was converted from 32-bit float WAV to 16-bit PCM WAV for smaller size and broad Unity compatibility.

# 「しわ賢者」UXデザイン依頼パッケージ

このZIPは、公開前のUX改善を外部UXデザイナーへ依頼するための資料一式です。

## 最重要条件

**Powaは現行デザインをそのまま使用してください。**

- キャラクターの描き直し、別キャラクター化、衣装変更、表情変更、配色変更は禁止です。
- 原画の縦横比を変形しないでください。
- レイアウト上の移動と等比率での拡大縮小は可能です。
- Powaを隠す、過度に切り抜く、UI部品で顔を覆う提案は避けてください。
- Powa以外も、既存の和風・木札・紙・朱色アクセントの世界観を基本として活用してください。

## まず読むファイル

1. `01_UXデザイン依頼書.docx` - 発注条件と全体方針
2. `02_画面別要件.md` - 画面ごとの修正要件
3. `03_遷移と状態.md` - 画面遷移と例外状態
4. `04_納品チェックリスト.md` - 納品物と受入条件
5. `references/REFERENCE_INDEX.md` - 同梱画像の説明

## 依頼の性質

新規ゲームのアートディレクションではなく、実装済みのUnity uGUIへ適用するUX改善です。独立画面はTitle、StageSelect、Main、Resultの4画面を維持し、必要な状態は既存画面内のdisabled、インライン表示、トースト、モーダルで解決してください。

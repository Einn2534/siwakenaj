# UXデザイン納品チェックリスト

## 納品物

- [ ] 編集可能なFigmaファイル、または合意済みの編集可能形式
- [ ] 主要画面遷移図
- [ ] 4独立画面の完成デザイン
- [ ] Pause、Settings、How To、Tutorial、Continue、データエラーのモーダル
- [ ] 広告待機／失敗、保存再作成、ロック、disabled、loading状態
- [ ] 再利用可能なButton、StageCard、HUD、Modal、Toast Component
- [ ] Unity実装用の寸法、spacing、font、anchor、表示条件
- [ ] 使用アセット一覧

## Powa保護

- [ ] Powaの形状を変更していない
- [ ] Powaの色を変更していない
- [ ] Powaの顔、衣装、ポーズを変更していない
- [ ] Powaを縦横に変形していない
- [ ] Powaの顔や主要部分をUIで隠していない
- [ ] Powa原本との比較画像がある

## ゲーム理解

- [ ] 初見で「車を見て下のButtonを押す」と理解できる
- [ ] 3車種と整備を区別できる
- [ ] 故障、覆面、急送をHow Toで再確認できる
- [ ] 目標進捗とミス残数が同時に読める
- [ ] Dailyの60秒・3ミスが明確
- [ ] Endlessの1ミス終了が明確

## 進行

- [ ] Titleからおしごとへ進める
- [ ] おしごと5クリア後のDaily/Endless解放が分かる
- [ ] StageSelectの3章 x 5面を移動できる
- [ ] スワイプ、前へ、次へが競合しない
- [ ] 最終面でNextが出ない
- [ ] ResultからRetry、StageSelect、Titleへ戻れる

## 例外

- [ ] StageDatabaseエラーで無言停止しない
- [ ] 未解放ステージを開始しない
- [ ] Rewarded広告失敗時にResultへ進める
- [ ] Rewarded広告Timeout時にResultへ進める
- [ ] Interstitial広告Timeout時にResult操作が解放される
- [ ] バックグラウンド復帰時にPauseされる
- [ ] Daily保存再作成は非ブロッキング通知になる

## 端末・操作

- [ ] 1080x1920で文字切れ、重なりがない
- [ ] 1170x2532で文字切れ、重なりがない
- [ ] 1440x3200で文字切れ、重なりがない
- [ ] Safe Area外へ主要操作が出ない
- [ ] 主要仕分けButtonが画面下半分にある
- [ ] 下端ジェスチャー領域とButtonが近すぎない
- [ ] 状態差が色だけに依存しない
- [ ] 最小タップ領域が一貫している

## 対象外確認

- [ ] ショップを追加していない
- [ ] コインを追加していない
- [ ] ガチャ、課金、ランキングを追加していない
- [ ] アカウント、ソーシャルを追加していない
- [ ] 新しい独立Sceneを追加していない
- [ ] ゲームルールやスコア式を変更していない

# Sorting theme art

Six original transparent PNG sprites generated with the built-in image_gen tool (no API fallback). Original outputs remain in the Codex generated_images directory. Selected PNGs are in Assets/Art/Sprites/SortingThemes; Unity imports preserve alpha. Clock and sealed parcel icons are exact vector drawings produced by Tools/Build-ThemeIcons.ps1.

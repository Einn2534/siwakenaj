# Powa 成功モーション：30 FPSテスト

## 0.8秒版

`Powa-success-30fps-0.8s.mp4` は成功動作を0.8秒に伸ばした版です。12枚を各2フレーム（1/15秒）表示し、動画は30 FPSです。前後の待機0.7秒ずつを含めて3回繰り返します（6.6秒、198フレーム）。0.4秒版も保持しています。

再生成：`./Build-Preview.ps1 -TimelineFile timeline-0.8s.json -FilterFile preview-filter-0.8s.txt -OutputFile Powa-success-30fps-0.8s.mp4`

## 0.4秒版

成功の0.4秒を12枚の異なる絵で再生する試作です。各コマは1/30秒。前後に待機を0.7秒ずつ置き、3回繰り返します（動画全体5.4秒）。

- 動画：`Powa-success-30fps.mp4`（640×640、H.264、30 FPS、162フレーム）
- 旧版との横並び比較：`Powa-6-vs-12-comparison.mp4`（左が旧6コマ構成、右が今回の12コマ構成）
- 原画：`frame-00.png`〜`frame-11.png`（全て1254×1254、透過PNG）
- コマ順一覧：`contact-sheet.png`（完成動画の成功区間から抜き出した12フレーム）
- 再生成：`Build-Preview.ps1`。一時的なハードリンク連番を作り、FFmpegに入力時から30 FPSを指定します。

## 素材

旧試作の5種類のキー画像を00・02・05・07・09に配置し、01・03・04・06・08・10・11を内蔵image_genで個別に新規生成しました。00は添付idol.pngです。最終プロンプト、参照画像、生成元の保存先は`generation-prompts.md`に記録しています。原本は保持しています。

## 確認結果

- 12枚のPNGは全て異なるSHA-256。
- 完成動画の全162フレームをエラーなくデコード。
- 成功区間のフレーム21〜32は12枚とも異なる画像。時間基準1/30、各フレームの長さ1を`reaction-frames.md5`で確認。
- 完成動画から作った一覧を目視し、杖は各コマ1本、顔と帽子の前後関係を確認。
- 帽子・バッジの線や形、裾には小さなコマ間の変化が残っています。元絵に含まれる輪郭の色にじみも残るため、完成素材ではなく30 FPSでの動き方を評価する試作です。

今回の変更はDeliverables内の試作用画像・動画・記録のみです。Main・Prefab・Animatorには未接続で、Unityのコンパイルやゲーム回帰テストは今回再実行していません。
